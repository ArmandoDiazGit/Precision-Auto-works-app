# Car Auto Repair App

A modern, responsive landing page for an auto repair service shop. Built as a front-end demo to showcase a clean, professional brand presence for an automotive repair business.

## Features

- **Responsive Design** — Fully responsive layout that works on desktop, tablet, and mobile
- **Glassmorphism UI** — Modern frosted-glass card components with backdrop blur effects
- **Smooth Scroll Navigation** — Fixed nav with smooth anchor scrolling to sections
- **Service Cards** — Grid of service offerings with hover effects and featured highlight
- **Trust Badges** — Stats strip showcasing experience, warranty, and customer satisfaction
- **Service Request Form** — Multi-field form with client-side validation and error feedback
- **Snackbar Notification** — Success snackbar on form submission with auto-dismiss
- **Mobile Hamburger Menu** — Collapsible navigation on smaller screens

## Tech Stack

- **React 19** — UI framework
- **Vite 8** — Build tool and dev server
- **CSS** — Custom styles with no external UI libraries

## Getting Started

### Prerequisites

- Node.js 18+ and npm

### Install

```bash
git clone https://github.com/ArmandoDiazGit/car-auto-repair-app.git
cd car-auto-repair-app
npm install
```

### Development

```bash
npm run dev
```

Opens at `http://localhost:5173` with hot module replacement.

### Build

```bash
npm run build
```

Produces an optimized build in the `dist/` folder.

### Preview

```bash
npm run preview
```
